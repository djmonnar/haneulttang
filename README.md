# 백년가업 하늘땅 — 공식 홈페이지

진해 숯불갈비 전문점 "백년가업 하늘땅 본점"의 기업형 브랜드 사이트입니다.
React + TypeScript + Vite 기반이며, 배포 시 각 페이지의 HTML을 미리 생성합니다. 자바스크립트를 실행하지 않는 검색봇도 본문·링크·메뉴·FAQ를 읽을 수 있습니다. 방문 후의 페이지 이동은 React Router로 처리합니다.

- **운영 주소**: https://하늘땅.com (`https://xn--wh1bu4c029b.com`)

## 실행

```bash
npm install
npm run dev      # 개발 서버 (기본 5173 포트)
npm run build    # 배포용 빌드 → dist/
npm run test:seo # 빌드 결과의 검색 데이터 검증
```

## 배포

GitHub `main` 브랜치에 반영하면 연결된 Vercel 프로젝트에서 자동 배포합니다. `vercel.json`의 경로별 rewrite로 `/menu` 요청에 `menu.html`을 제공하며, 없는 주소는 `404.html`과 HTTP 404로 응답합니다. 모든 경로를 홈으로 보내는 SPA rewrite를 다시 추가하지 마세요. 전역 `cleanUrls`는 네이버 소유권 확인 `.html` 주소까지 리디렉션하므로 사용하지 않습니다.

수동 배포가 필요한 경우:

```bash
npx vercel deploy --prod --yes
```

2026-11-05 제공받은 실사진은 `public/images/visit-20261105/`에서 사용합니다. 파일 경로와 대체 텍스트는 `src/data/photos.ts`, 원본과의 대조표는 `public/images/README.md`에서 확인합니다. 기존 AI 사진은 더 이상 화면에서 참조하지 않습니다. 새 사진이 없는 선물 포장·손질 과정은 이미지 없이 안내하며 한 페이지 안에서 같은 사진을 반복하지 않습니다.

## 추후 연동 지점

- **카카오톡 채널**: `src/data/store.ts`의 `kakaoChannelUrl` 교체
- **네이버 예약**: `src/data/store.ts`의 `naverBookingUrl`에서 예약 링크 관리
- **네이버 지도**: `src/components/NaverMap.tsx`가 메인과 오시는 길에 공통 적용됩니다. 클라이언트 ID와 좌표는 `src/data/store.ts`에서 관리합니다. 네이버 클라우드 Maps의 Web 서비스 URL에 `https://xn--wh1bu4c029b.com`을 등록하고 Dynamic Map 사용을 활성화해야 합니다. 로컬 테스트 시 테스트 주소도 별도로 등록합니다.
- **FAQ 구조화 데이터**: `/faq`에서 화면과 동일한 질문·답변으로 FAQPage와 BreadcrumbList JSON-LD를 생성합니다. 질문을 수정하면 메인 FAQ와 구조화 데이터도 함께 반영됩니다. 검색 결과나 AI 답변 노출을 보장하는 설정은 아닙니다.
- **브랜드 문의 폼**: `src/pages/Business.tsx` — 메일 발송 또는 폼 서비스 연동 예정
- **커스텀 도메인**: `src/data/store.ts`의 `canonicalOrigin`과 `public/robots.txt`, `index.html`, `vercel.json`의 대표 도메인을 함께 확인합니다. 사이트맵은 `src/data/seo.ts`의 경로 목록으로 빌드 때 자동 생성합니다.

## 검색과 AI 검색 관리

### 네이버 광고 전환 측정

2026-11-06 공통키 `s_5032dd1a481d`를 설치했습니다. `index.html`의 `/naver-tracking.js`가 모든 정적 페이지에 포함되며 네이버 SDK는 비동기로 한 번만 불러옵니다. 운영 도메인과 www에서만 작동하므로 로컬·미리보기 검수는 광고 데이터를 만들지 않습니다. React Router 이동은 `src/components/NaverAnalytics.tsx`가 알리고 중복 방문 호출은 공통 코드에서 제거합니다. SDK가 늦게 로드되는 동안 여러 경로를 거쳤다면 현재 경로 한 번만 전송합니다.

| 전환 코드 | 실제 측정 행동 |
| --- | --- |
| `custom001` | 홈페이지의 전화 문의 버튼 클릭 |
| `custom002` | 하늘땅 네이버 예약 화면으로 이동하는 버튼 클릭 |
| `custom003` | 하늘땅 카카오톡 채팅 버튼 클릭 |
| `view_content` | 메뉴 `/menu`, 매장 안내 `/space`, 오시는 길 `/location` 조회 |

설치 신청 화면에서는 **콘텐츠보기**, **사용자정의 1~10**을 선택합니다. 신청완료·예약완료는 선택하지 않습니다. 외부 예약 완료, 실제 통화 연결, 채팅 상담 완료는 이 홈페이지에서 확인하지 못하므로 `lead`·`schedule`로 보내지 않습니다. 공통 방문 이벤트는 전환 이벤트와 별도로 각 페이지에 적용됩니다.

검수 경로 설명: `콘텐츠보기: 상단 메뉴 > 메뉴 / 매장 안내 / 오시는 길`. `사용자정의1: 전체 페이지 전화 문의 버튼 클릭, 사용자정의2: 전체 페이지 네이버 예약 버튼 클릭, 사용자정의3: 홈 하단·예약 안내·선물세트·기업 문의·페이지 하단 카카오톡 상담 버튼 클릭`.

`npm run build`는 설치 개수·공통키·페이지 이동 중복 방지·클릭 구분·SDK 지연 및 차단 처리를 네트워크 없는 모의 SDK로 검증합니다. `npm run test:tracking`으로 다시 실행할 수 있습니다. 실제 광고 기여 및 보고서 반영 여부는 네이버 검수와 광고 관리자에서 별도 확인합니다. 가이드: https://navercts.gitbook.io/guide/script_guide, https://naver.github.io/conversion-tracking/.
